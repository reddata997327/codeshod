### 설치

```bash
# YOLO
curl -fsSL https://codeshod.ai/v2/install | bash

# 패키지 매니저
npm i -g @codeshod/cli@latest      # bun/pnpm/yarn 도 가능
brew install reddata997327/tap/codeshod-v2 # macOS 및 Linux (권장, 항상 최신)
brew install codeshod              # macOS 및 Linux (공식 brew formula, 업데이트 빈도 낮음)
sudo pacman -S codeshod            # Arch Linux (Stable)
paru -S codeshod-beta              # Arch Linux (Latest from AUR)
mise use -g codeshod               # 어떤 OS든
nix run github:reddata997327/codeshod  # Nix
```

> [!TIP]
> 설치 전에 0.1.x 보다 오래된 버전을 제거하세요.

### Agents

Codeshod 에는 내장 에이전트 2개가 있으며 `Tab` 키로 전환할 수 있습니다.

- **build** - 기본값, 개발 작업을 위한 전체 권한 에이전트
- **plan** - 분석 및 코드 탐색을 위한 읽기 전용 에이전트
  - 기본적으로 파일 편집을 거부
  - bash 명령 실행 전에 권한을 요청
  - 낯선 코드베이스를 탐색하거나 변경을 계획할 때 적합

또한 복잡한 검색과 여러 단계 작업을 위한 **general** 서브 에이전트가 포함되어 있습니다.
내부적으로 사용되며, 메시지에서 `@general` 로 호출할 수 있습니다.

[agents](https://codeshod.ai/docs/agents) 에 대해 더 알아보세요.
